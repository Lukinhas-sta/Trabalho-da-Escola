# LUKINHAS Play

Projeto escolar de catálogo de filmes e séries, preservado como parte da minha evolução no desenvolvimento web.

## Sobre

A primeira versão nasceu como um exercício simples de HTML e CSS. Em 2026, o projeto foi modernizado mantendo a proposta original, mas ganhando uma interface responsiva, catálogo interativo e troca de trailers com JavaScript puro.

## Recursos

- Destaque principal com trailer incorporado
- Catálogo horizontal no celular e em grade no desktop
- Troca do trailer ao selecionar um card
- Interface responsiva e acessível
- Sem backend, banco de dados ou Supabase

## Tecnologias

HTML5, CSS3 e JavaScript puro.

> Mantido no GitHub como registro da minha evolução desde os primeiros projetos escolares.
