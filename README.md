## 📖 História do projeto

A primeira versão nasceu como um trabalho escolar: uma página simples inspirada em um catálogo de filmes, construída enquanto eu aprendia HTML e CSS.

Em 2026 decidi não apagar esse começo. Em vez disso, modernizei o projeto mantendo a proposta original e transformando-o em uma pequena experiência de streaming estática chamada **LUKINHAS Play**.

### Antes

- Página simples em HTML e CSS
- Trailer fixo
- Lista básica de vídeos
- Pouca adaptação para celular
- Estilos iniciais de quem estava aprendendo desenvolvimento web

### Hoje

- Interface moderna inspirada em plataformas de streaming
- Hero com trailer em destaque
- Catálogo interativo
- Seleção de cards atualizando o conteúdo principal
- JavaScript puro para interação
- Responsividade para celular e desktop
- Melhor organização visual, estados de foco e hover
- Sem backend, banco de dados ou Supabase

## 🧠 O que aprendi

A versão original ajudou a praticar **estrutura HTML, CSS, incorporação de mídia e organização de conteúdo**. A revitalização adicionou conceitos de **responsividade, experiência do usuário, manipulação do DOM e JavaScript**, deixando visível a diferença entre o início e o estágio atual dos meus estudos.
